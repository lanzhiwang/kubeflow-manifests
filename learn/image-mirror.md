* ghcr.io 是 GitHub Container Registry 的域名, 它是 GitHub 提供的用于存储、管理和分享Docker 容器镜像的注册表服务
* quay.io 是一个由红帽(Red Hat)提供的托管容器镜像仓库服务
* gcr.io 是 Google Container Registry(GCR) 的缩写, 它曾是 Google Cloud 的一个容器镜像仓库服务
